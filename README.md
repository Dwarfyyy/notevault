# NoteVault

Учебное desktop-приложение для ведения личной базы знаний в духе **Obsidian**: заметки в Markdown, связи между заметками через `[[wiki-ссылки]]`, бэклинки, теги, полнотекстовый поиск и визуальный граф связей.

Написано на **Python** (ядро — чистый Python, интерфейс — PySide6).

## Возможности

- **Хранилище (vault)** — обычная папка с `.md`-файлами, никакой проприетарной базы;
- **Markdown-редактор** с подсветкой синтаксиса и live-предпросмотром;
- **Wiki-ссылки** вида `[[Название заметки]]` и `[[Заметка|текст]]`;
- **Бэклинки** — панель «на эту заметку ссылаются…»;
- **Теги** `#тег` с индексом и фильтрацией;
- **Полнотекстовый поиск** по всему хранилищу с выдачей контекста;
- **Граф связей** — интерактивная визуализация сети заметок;
- **Ежедневные заметки** — создание заметки на сегодня одной кнопкой.

## Структура проекта

```
notevault/
├── main.py                 # точка входа
├── notevault/
│   ├── core/               # ядро (не зависит от GUI)
│   │   ├── note.py         # модель заметки, парсинг ссылок и тегов
│   │   ├── vault.py        # хранилище: загрузка, сохранение, индексация
│   │   ├── links.py        # wiki-ссылки и бэклинки
│   │   ├── search.py       # полнотекстовый поиск
│   │   └── graph.py        # построение графа связей
│   └── ui/                 # интерфейс на PySide6
│       ├── app.py          # главное окно
│       ├── editor.py       # редактор с подсветкой
│       ├── preview.py      # предпросмотр Markdown
│       └── graph_view.py   # виджет графа
├── tests/                  # pytest-тесты ядра
└── examples/demo_vault/    # демонстрационное хранилище
```

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py                      # откроется demo-хранилище
python main.py --vault path/to/dir  # открыть своё хранилище
```

Для запуска только ядра (без GUI) достаточно стандартной библиотеки Python 3.10+.

## Тесты

```bash
python -m pytest tests/ -v
```
